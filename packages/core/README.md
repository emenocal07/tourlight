# @emenocal07/tourlight-core

Framework-agnostic core of [Tourlight](https://github.com/emenocal07/tourlight): the
tour state machine (a pure reducer), step ordering and config validation, and the
persistence contract (`TourStorage`) with its "show N times" progress logic.

It has no React and no DOM dependency, so it can back other renderers.

Most users want the React package instead:
[`@emenocal07/tourlight`](https://github.com/emenocal07/tourlight#readme), which
depends on this one.

Source, issues and documentation: https://github.com/emenocal07/tourlight
